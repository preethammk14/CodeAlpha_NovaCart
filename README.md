</p>📌 About the Project

NovaCart is a modern e-commerce web application designed to provide customers with a smooth, convenient, and premium online shopping experience.

The platform brings multiple shopping categories together in one place, offering product discovery, shopping cart management, customer authentication, promotional offers, order management, and online payment integration.

This project was developed as part of my CodeAlpha internship task.

✨ Key Features

- Product Catalogue: Browse products across six categories.
- Shopping Cart: Add products and manage cart items.
- User Authentication: Customer registration and login.
- Admin Dashboard: Dedicated administrative interface.
- Order Management: Place orders and track order status.
- Promotional Offers: Discount coupons and promotional deals.
- Secure Checkout: Customer and delivery information validation.
- Payment Integration: Razorpay test-mode payment integration and Cash on Delivery.
- Responsive Interface: Designed for a convenient shopping experience.

🛒 Shopping Categories

1. Electronics
2. Fashion
3. Home & Living
4. Beauty
5. Accessories
6. Sports & Fitness

🛠️ Technology Stack

- Google AI Studio – AI-assisted application development
- React – Frontend development (if applicable to the final project)
- Firebase – Backend services and application data
- Razorpay – Payment gateway integration (test mode)

💳 Payment Information

NovaCart currently uses Razorpay in test mode for demonstration and testing purposes.

Important: Test transactions do not represent real-money payments. Live payment processing requires the appropriate Razorpay account activation and production configuration.

🔐 Security

- Customer and administrator access should be protected through authentication and server-side authorization.
- Sensitive payment credentials must be stored in environment secrets.
- Firebase security rules should restrict unauthorized data access.
- Never commit private API secrets or credentials to GitHub.
